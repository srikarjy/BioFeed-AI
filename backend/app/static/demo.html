BioFeed AI — live demo

Hitting the real, deployed API in your browser — every request below is a live call, nothing here is mocked.

This free-tier deployment runs with EMBEDDING_BACKEND=hash (deterministic, dependency-free token-hashing) instead of the real PubMedBERT model reported in METRICS.md, so search/related-article results are topically rough, not true semantic matches — a RAM tradeoff for a $0/mo host. The self-hosted vLLM anomaly-explanation feature is not live here (real GPU spend); it was verified separately on a real GPU — see ANOMALY_EXPLAIN_LLM.md in the repo. First request after idling may take 30–60s to wake the free instance up.

Personalized feed & explanation

POST /auth/apple (fake identity provider, dev/test path — real deployments verify Sign in with Apple/Google JWKS) → GET /users/{id}/feed → GET /users/{id}/articles/{id}/explain. A fresh demo user has no interaction history, so the feed starts in cold-start (content-similarity) mode — labeled honestly below, not hidden.
